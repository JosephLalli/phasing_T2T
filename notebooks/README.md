# Notebooks

This directory contains Jupyter notebooks for data analysis, figure generation, and statistical computation.

## Directory Structure
- Main directory - Test-region analysis notebooks
- `notebooks_whole_genome/` - Publication-scale summary and figure notebooks

## Core Analysis Notebooks

### Primary Publication Notebooks
- **calc_figures_for_paper.ipynb** - Calculates all values reported in manuscript text
  - Summary statistics across populations and chromosomes
  - Switch error rate calculations  
  - Imputation accuracy measurements
  - Designed to run on laptop with summary data
  
- **calc_per_variant_figures_for_paper.ipynb** - Per-variant detailed analysis
  - Requires loading full variant dataframes into memory
  - Variant-level switch error analysis
  - Regional and population-specific variant patterns
  - Requires high-memory server environment

- **notebooks_whole_genome/make_plots.py** and **make_plots.ipynb** - Current figure workflow
  - Edit the Jupytext `py:percent` source, then sync and validate the notebook
  - Generate main, Extended Data and supplementary figure outputs
  - Use `PHASING_T2T_RUN_PROFILE=whole_genome` for publication inputs or `test` for test-region inputs
  - Figure 5 is generated by `scripts/figure5/Figure_5_script.R` and its SVG stitcher
  - `figure_composition.py` composes vector panels; `utilities.py` retains plotting and data helpers

See the
[repository figure workflow](../README.md#publication-figure-code) for
the public `NG-TR68126R` input-release contract, isolated Docker execution,
and the current figure-to-output mapping. Reviewer runs should use
`scripts/run_publication_notebook.sh`; it verifies all 188 packaged inputs and
executes the canonical whole-genome notebook. Figure 5 remains the separate
existing R workflow and is not regenerated by this notebook command.

## Data Dependencies

### Input Data Sources
- `intermediate_data/` - Test-region summary analysis files
- `imputation_statistics/` - Test-region imputation results
- `intermediate_data_whole_genome/` - Complete genome-wide analysis results
- `imputation_statistics_whole_genome/` - Complete genome-wide imputation results
- `SHAPEIT5_switch_output/` - Switch error calculations

### Output Locations
- `figures/` and `tables/` - Test run figures and tables
- `figures_whole_genome/` and `tables_whole_genome/` - Publication-scale figures and tables
- Inline notebook outputs - Interactive analysis results
