# Phased Panels

This directory contains phased haplotype panels generated by the T2T phasing pipeline.

## Directories

- `phased_CHM13v2.0_panel_*/`: T2T-CHM13 phased panels
- `phased_GRCh38_panel_*/`: GRCh38 phased panels

## Panel types

### Full sample panels (3,202 samples)

- All samples, including trio children and parents.
- Pedigree-informed phasing using family relationship data.
- Used for method validation and accuracy assessment.

### Unrelated sample panels (2,504 samples)

- The 2,504-sample unrelated subset.
- Suitable for downstream imputation and analysis.

## Published T2T-CHM13 panels

Published T2T-CHM13 panels are available from the [T2T/HPRC bucket browser](https://s3-us-west-2.amazonaws.com/human-pangenomics/index.html?prefix=T2T/CHM13/assemblies/variants/1000_Genomes_Project/chm13v2.0/Phased_SHAPEIT5_v1.1/). They are distributed as BCF files with matching CSI indexes; download both files for each panel you use and keep each index beside its BCF.

## GRCh38 comparison panels

From the repository root on your host machine, use the command in the [main README](../README.md#phase-1kgp-variation-and-calculate-summary-statistics) to download and prepare the GRCh38 comparison panels. It downloads the upstream phased VCFs, stores them under the names used by this pipeline, and uses the tools in the Docker image to prepare the 2,504-sample biallelic BCF panels used for imputation comparisons.
